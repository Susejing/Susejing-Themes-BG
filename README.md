# Susejing Themes BG

Temas Kino con **imagen de fondo** (apiVersion 26).

## Instalación en Kino

1. Plugins → Agregar
2. Escribe: `Susejing/Susejing-Themes-BG`
3. Ajustes → Apariencia → elige el tema

## Temas incluidos

| Id | Nombre | Acento |
|----|--------|--------|
| ninja-night | Ninja Noche | Cian |
| nte-city | NTE Ciudad | Violeta |
| nte-spiral | NTE Espiral | Cian |
| nte-neon | NTE Neón | Rosa |
| golden-field | Campo Dorado | Ámbar |
| sunset-duo | Atardecer | Naranja |
| princess-gold | Princesa Dorada | Azul cielo |
| zzz-crew | ZZZ Crew | Amarillo |

Cada tema incluye `background.image` con `dim ≥ 0.36` y paleta acorde.
